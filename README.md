# Staff Portal

Part of the School ERP Ecosystem — repository 04 of 5. A thin placeholder for
the real teacher-facing app, demonstrating how it would integrate the
[XYZ AI](https://github.com/Khushi-Tyagi9/xyz-ai) assistant.

Open `index.html` directly in a browser — no build step. The "Ask XYZ AI"
button embeds the real chat UI (`http://localhost:5173` by default; run the
xyz-ai frontend first) in a panel. Try "Mark Rahul absent today" logged in
as a Teacher.
